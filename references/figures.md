# 给场景和技术方法配图

每张图先定用途和落点。一张总图可以带出多个任务，再在关键子任务下安排局部图。仅需解释两个数值或一个简单步骤时，表格或一句话也足够。

## 场景图：把限制画在发生的位置

选图前从正文找出三个实际要素：研究对象、作业动作、导致困难的现场条件。需要证明已勘察、已部署或已试验时用有来源的现场材料。解释拟实施场景时，可调用 GPT 生图生成工程示意，把“AI 生成”写入图注。用户名下的现场点位、设备编号以及未公开的内部图纸，如非必要可用通用对象描述替代。

**可改写的提示词。** 为“山区配网终端通信”生成一幅横向场景示意。近处是杆旁采集箱，远处是山谷居民点和山脊上的通信站，中间山体遮挡两端直视路径。让读者一眼辨认设备、站点与地形的空间关系。采用自然日光和适合印刷的工程插画风格。画面不放单位名称、实测值、指示箭头或长文字，说明标签后续排入正文。

[查看这条思路生成的实际样图](../assets/山区配网场景示意_AI生成.png)。可配图题“图 X　山区配网终端与通信站的地形关系（场景示意，AI 生成）”。图前交代为什么选型时要考虑站点之间的地形，图后说明应结合哪些勘测资料开展覆盖分析。图只说明空间关系，实际通信距离或覆盖效果须另有测量依据。新题材按本项目重新生图，检查设备形态、相对位置、布线、作业动作和可能误读的细节，再把核准的图题和标签排入 Word 或 PPT。

## 从论文取框架图、网络图

1. **按拟解释的方法找原图。** 从原始论文的 DOI、出版社、会议或作者公开版本进入。阅读相应方法段、原图和图注，核对是哪种输入，经什么模块，训练目标是什么。搜索页缩略图只能用来定位。留意同名论文的正式版和预印本图号可能不同。
2. **挑选能复核的素材。** 记下作者、题名、年份、版本、图号、页码（有页码时）、链接和该图的署名或许可。对照实际用图方式查询文章及第三方图片的转载、改绘条件；原站有独立高清图时优先原图。对于暂时拿不到或不能直接复用的图，可以依论文描述自行设计说明图，注明依据，继续写清方法。
3. **从 PDF 裁取。** 只有整页 PDF 时，先在目标页确认图的边界，再裁出含完整模块、箭头、坐标、单位、图例和必要子图标号的区域。原图号与图注抄入来源记录，项目正文另用本子图号。可用 PDF 裁图工具，或用包内[取图脚本](../scripts/crop_paper_figure.py)完成下方操作。
4. **写清借用关系。** 图前用一两句交代文献解决的问题。引原图标“引自……图 X”，说明翻译或局部裁切；自绘并改变拓扑时标“据……绘制/改绘”，说明保留和修改了哪些模块。图后落到本项目的选用条件、适配工作或尚待验证之处。有人报告的性能只能归于其公开实验。需要标识本项目架构时，另用可编辑 PPT 画出真实输入、模块和接口。

[已核对的论文配图实例](paper-example.md)包含一张真实网络图、原文定位、可用图注，以及如何在 OTDR 项目里说明方法差异。仅在该方法确实相关时选用。

### 裁图命令举例

在已包含 `pypdfium2` 和 Pillow 的 Python 环境中运行。桌面环境优先使用配套文档运行环境。以下命令假设当前位置是 skill 目录，输入文件名和页号应换成本次论文的实际值。

```text
python scripts/crop_paper_figure.py paper.pdf --page 4 --dpi 100 --out page-preview.png
python scripts/crop_paper_figure.py paper.pdf --page 4 --box 0.10 0.18 0.92 0.67 --dpi 300 --out method-figure.png
```

第一条生成整页预览。第二条里的四个数是左、上、右、下四条边在可见页面的位置，以左上为原点，各用 0 至 1 的比例表示。这里的边界只是命令示例；用实际图的位置替换。最后打开裁图，核对原图号和边缘标注，在本子最终栏宽下确认清晰度。原 PDF 内嵌的低清图不会因提高导出分辨率而增加细节。
