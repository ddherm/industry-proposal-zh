# 新范本待处理目录

将希望继续学习的 Word、PDF、PPT 或图片上传到这里。文件名带上题材和版本，多个文件属于同一本时放在同一个子文件夹中。

## 通过 GitHub 网页上传

1. 打开这个目录的文件列表，选择 **Add file → Upload files**。
2. 拖入新文件。填提交说明，例如“加入冷链项目可研 V2，用于学习研究内容与技术路线”。
3. 点击 **Commit changes**。
4. 回到对话，给出仓库链接、新文件名及重点，例如“提炼第2章的研究内容写法和图5的任务衔接，更新这个 skill 并同步本机”。

网页上传每个文件上限为 25 MiB。25 至 100 MiB 的文件可通过本地 Git 上传；超过 100 MiB 需要 Git LFS。遇到较大的本子，可以先放到本地项目文件夹，告知文件路径，由助手处理上传方式。[GitHub 文件上传说明](https://docs.github.com/en/repositories/working-with-files/managing-files/adding-a-file-to-a-repository?platform=windows)

## 在本机添加

本项目的本地目录为 `E:\项目工作\优质本子\industry-proposal-zh\templates\inbox`。把文件放进来后，在对话里说明文件名、希望借鉴的内容，以及要更新 GitHub 和本机 skill。

## 怎样提出更新要求

说明你最喜欢哪一节、哪段文字或哪张图。也可直接说“请自行找出值得吸收的写法”。有新的甲方表式时，说明它适用于哪类本子。有新的 PPT 框架图时，指出它适合整体任务关系、子任务路线还是网络结构。

完成蒸馏后，在 [范本目录](../catalog.md) 记录已经核对的章节、图号、吸收位置及处理状态。保留原始文件供后续复核。
